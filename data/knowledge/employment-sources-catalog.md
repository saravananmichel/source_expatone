## Remediation Details

### Tier 1 — Replaced with verified sources

**#9 (Section 60K):** Old invented URL returned 404. Real content discovered at `http://jtksm.mohr.gov.my/ms/perkhidmatan/penggajian-pekerja-asing-0`. Page contains detailed Section 60K information including 6 foreign worker categories, ePPAx system, FWCMS, and Xpats Gateway. Content extracted directly from verified page.

**#13 (Foreign Worker Rights):** Old URL returned 403. No single JTKSM page covers all foreign worker rights. Replaced with PERKESO's official foreign worker page (`perkeso.gov.my/en/our-services/protection/foreign-worker.html`) which contains verified contribution rates, benefit details, and employer obligations. Coverage of general Employment Act rights for foreign workers is distributed across other JTKSM sources (#2, #3, #4).

**#17 (Industrial Relations / Unfair Dismissal):** Old URL was the JPP homepage — no Section 20 content on that page. Real Section 20 page found at `jpp.mohr.gov.my/ems-pembuangan-kerja-seksyen-20/`. Contains verified procedure: 60-day filing limit, ADR conciliation, MOA, Industrial Court referral, representation rules. Content extracted directly.

**#19 (SIP/Employment Insurance):** Old URL returned 404. Real page found at `perkeso.gov.my/en/our-services/protection/employment-insurance.html`. Contains verified eligibility, loss-of-employment types, 5 benefit categories with amounts (JSA, RIA, ERA, TF, TA), and claim instructions. Content extracted directly.

### Tier 2 — Deactivated (no verifiable replacement found)

**#11, #12 (Employment Act 1955 core provisions):** The JTKSM `/akta-dan-peraturan/` section returns 404 for all tested URL patterns. The AGC legislation database (`lom.agc.gov.my`) is accessible at the homepage but its search function returns HTTP 500. No accessible online source of the Employment Act 1955 text was found. These sources are deactivated rather than keeping synthetic legislative content with false attribution.

**#14 (Minimum Wage):** The MOHR website (`mohr.gov.my`) refuses all connections. The RM1,500 rate cannot be verified as current for September 2026. Deactivated.

**#16 (Employment Contracts):** The JTKSM `/akta-dan-peraturan/kontrak-perkhidmatan` URL returns 404. No accessible official source for the Standard Foreign Worker Contract was found. Deactivated.

**#18 (EPF Foreign Worker Coverage):** The KWSP website (`kwsp.gov.my`) returns 403 on all pages. EPF contribution rates and foreign worker rules cannot be verified. Deactivated.

### Tier 3 — Cleaned (removed content beyond page)

**#4 (Worker Complaints):** Reduced to match actual page content. Removed detailed investigation types and foreign worker exploitation items not on the cited page.

**#5 (Retrenchment):** Reduced to match actual page content. Removed termination benefit rates and referral agencies (PERKESO/HRDC/TalentCorp) not stated on the page. Termination benefit rates should be restored only when sourced from the actual Employment Act text.

**#7 (Worker Housing):** Reduced to match actual page content. Removed detailed accommodation standards, enforcement details, and foreign worker notes not on the cited page.

**#8 (Wage Payment Instruments):** Reduced to match actual page content. Removed payment frequency rules, deduction caps, and foreign worker provisions not on the cited page. Added new FAQ source (#8b) with verified content from the JTKSM FAQ page.

**#20 (Labour Permits):** Reduced to match actual page content. Added new FAQ source (#20b) with verified content from the JTKSM FAQ page including 12 exemption types and processing times.
